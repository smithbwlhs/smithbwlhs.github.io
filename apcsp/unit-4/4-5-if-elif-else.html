If, Elif, Else

if/else picks between two paths. Real decisions often have more: hot, warm, or cool; A, B, C, D, or F. elif lets you line up as many choices as you need, and Python runs exactly one. Drag the slider to see which branch wins.

01First True wins

  
An if/elif/else chain is checked from the top down:

  
    
    
  1. Python checks the if condition. If it’s True, that body runs and the rest of the chain is skipped.
    2. 
    
  2. If not, it checks the first elif, then the next, and so on. The first one that’s True wins.
    3. 
    
  3. If none are True, the else body runs. The else is optional; without it, nothing runs.
    4. 
  

  
Once a branch wins, Python doesn’t even look at the conditions below it. Example 4.5.4 Study Plan has six branches. Try the boundary values: what happens at exactly 5 hours?

  

    
Lab: run 4.5.4 Study Plan

    

  

  
Each elif already knows something. When Python reaches elif hours > 3, every condition above it was False, so it already knows hours is not more than 5. That’s why each branch needs only one comparison.

03Choosing a pattern

  
The notes in 4.5.3 compare these patterns. The question to ask is always: how many of these blocks should be able to run?

  

    
PatternHow many blocks runUse it when

    
if0 or 1Something happens only sometimes, and otherwise nothing happens.

    
if / elseexactly 1 of 2There are exactly two outcomes.

    
if / elif / elseexactly 1 of manyThere are several categories and only one can be the “winner.”

    
separate ifsany numberEach check is independent, so several can be true at once.

    
nested ifdependsOne decision only matters after another one, like checking a score only if homework was turned in.

04No gaps, no overlaps

  
When the input can be a decimal (you’ll read it with float()), every possible number has to land in some branch. Ranges written like “80 to 89” leave holes: where does 89.5 go? Compare these two grade programs.

  


# Version 1: ranges on both ends
if pct >= 90:
    grade = "A"
elif pct >= 80 and pct <= 89:
    grade = "B"
elif pct >= 70 and pct <= 79:
    grade = "C"
else:
    grade = "F"


# Version 2: one cutoff per branch
if pct >= 90:
    grade = "A"
elif pct >= 80:
    grade = "B"
elif pct >= 70:
    grade = "C"
else:
    grade = "F"

05Checking text

  
Chains work with strings too: compare the input to each choice with ==, and use else to catch anything you didn’t expect. Two things to watch:

  
    
    
  • Exact match. "Dog" == "dog" is False. Capitals and extra spaces count.
    • 
    
  • Each side of or needs a full comparison. This is the 4.3 rule again, but with strings the mistake doesn’t crash. It quietly gives the wrong answer.
    • 
  

  

    
Lab: the sneaky or

    

  

  
Why is the left one always True? Python reads it as (pet == "cat") or ("Cat"). The right side is just the string "Cat", and in 4.1 you saw that any non-empty string counts as True. So the whole condition is True no matter what the user types.







  
06On the AP exam

  
The AP reference sheet (that’s 4.5.10) has IF and IF/ELSE, but no ELSE IF. A chain with more than two outcomes is written by putting another IF inside the ELSE block. It works exactly like elif.

  


# Python
if temp >= 80:
    print("Hot")
elif temp >= 60:
    print("Warm")
else:
    print("Cool")


// AP pseudocode
IF (temp ≥ 80)
{
   DISPLAY("Hot")
}
ELSE
{
   IF (temp ≥ 60)
   {
      DISPLAY("Warm")
   }
   ELSE
   {
      DISPLAY("Cool")
   }
}
