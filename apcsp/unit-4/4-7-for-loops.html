01Anatomy of a for loop

Example 4.7.3 For Loop is just two lines:

for i in range(3):
    print(i)
PartJob
range(3)Makes the numbers 0, 1, 2. It starts at 0 and stops before 3, so there are exactly 3 numbers.
iThe loop variable. Each time through, it holds the next number from range.
: and the indentSame rule as if: the indented lines are the body, and they run once for each number.

Step through it. Try range(0) too: what happens when there are no numbers at all?

The off-by-one trap: range(5) gives 0, 1, 2, 3, 4. It runs 5 times, but the last value of i is 4, not 5.







  
02Repeat N times

The number can come from the user. range() needs a whole number, so the input has to go through int() first, the same as in 4.3.

04Drawing with loops

  
In The Worm and Caterpillar, the loop draws one circle per pass, and i decides where each one goes. Two numbers have to be right:

  
    
    
  • The radius, so that NUM_CIRCLES circles side by side are exactly as wide as the canvas. Each circle is 2 * RADIUS wide.
    • 
    
  • Each circle’s x position, which is its center. The first center is one radius in from the left edge, and each new circle moves right by one diameter.
    • 
  

  
Names in ALL CAPS like NUM_CIRCLES and RADIUS are constants: values set once and not changed. Using get_width() and get_height() instead of typing numbers means the drawing still fits if the canvas or NUM_CIRCLES changes.

05Building up a total

  
A very common loop pattern keeps a running total: create a variable before the loop, then change it inside the loop. Here a runner adds 400 meters each lap and reports the distance so far.

Where a line goes decides how often it runs. Above the loop: once. Indented inside the loop: every pass. Below the loop (not indented): once, after the loop is done. If you only want to print the final total, the print goes below the loop.







  
06On the AP exam

  
The AP reference sheet’s simplest loop is REPEAT n TIMES. It matches a Python for loop that doesn’t use i.

  


# Python
total = 0
for i in range(3):
    total = total + 5
print(total)


// AP pseudocode
total ← 0
REPEAT 3 TIMES
{
   total ← total + 5
}
DISPLAY(total)

  

  
There’s no i in REPEAT n TIMES. If an exam question needs a counter, it creates its own variable and adds 1 to it inside the loop. The reference sheet has two other loops, REPEAT UNTIL and FOR EACH, which you’ll meet with while loops and lists.

  
Exam questions often ask what’s displayed after a loop. Trace it with a table: one row per pass, one column per variable, exactly like the labs on this page.
