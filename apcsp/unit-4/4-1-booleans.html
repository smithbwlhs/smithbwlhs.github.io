01Only two values

A Boolean is a value that can only ever be one of two things: True or False. It’s named after George Boole, a mathematician who worked out the rules for reasoning with true and false in the 1800s, long before computers existed.

You already know three Python types from Unit 3: int (whole numbers), float (decimals), and str (text). Booleans are the fourth, and Python calls the type bool.

print(type(True))    # <class 'bool'>
print(type("True"))  # <class 'str'>   the quotes make it text
print(type(1))       # <class 'int'>

Two rules Python is strict about: the first letter must be a capital (True, never true), and there are no quotes. true gives a NameError because Python thinks you mean a variable that doesn’t exist, and "True" is just a string of four letters.

02Boolean variables

  
You store a Boolean in a variable the same way as any other value. Good Boolean names read like a yes-or-no question, so the code explains itself: is_raining, has_key, game_over, can_vote.


light_on = False
print(light_on)   # False

light_on = True     # reassign: the old value is replaced
print(light_on)   # True

  
Like any variable, it holds one value at a time. Assigning a new value replaces the old one completely.

Printing a Boolean with a label

  
A bare True on the screen doesn’t tell the user much. The CodeHS examples print a label in front of the value, like this line from 4.1.3 First Boolean:


print("User logged in?: " + str(logged_in))   # User logged in?: False

  
The + sign can only glue a string to another string. str() turns the Boolean into the text "False" so the two can be joined. Leave it out and Python stops with an error:


print("User logged in?: " + logged_in)
# TypeError: can only concatenate str (not "bool") to str

  
Another way: print("User logged in?:", logged_in) also works. A comma lets print show several values, adds one space between them, and converts the Boolean for you, so no str() is needed.

04The bool("False") trap

  
In Unit 3 you used int(input(...)) to turn typed text into a number. It’s tempting to try the same thing with Booleans, but bool() doesn’t read the words. For a string, it only asks “is this string empty?” Any string with at least one character, including "False" and "no", becomes True.

05On the AP exam

  
The AP exam doesn’t use Python. It uses its own pseudocode, shown on the reference sheet you’ll have during the test. Booleans work the same way, but they look a little different.

Watch the capitals. AP pseudocode writes true in lowercase, and that’s correct there. In Python, lowercase true is an error. Keep the two languages straight by asking “am I writing Python or reading the exam?”

4.1.4 Do You Have a Cat?

  
Hint 1: naming the variable
    
The instructions don’t give you a name, so you choose one. Pick a name that reads like a yes-or-no question about you, using the naming style from section 02.

  

  
Hint 2: giving it a value
    
The value is one of Python’s two Boolean values. Check the capital letter, and make sure there are no quotation marks around it. If you print type() of your variable, it should say <class 'bool'>, not <class 'str'>.

  

  
Hint 3: printing it
    
The instructions say to print the value of your Boolean, and the starter comment asks for an informative message. That means a label and the value, using one of the two ways in section 02. If you join with +, remember str().

  

  
Hint 4: if the autograder disagrees with you
    
Common causes: a lowercase true, quotes that turned your Boolean into a string, a TypeError from + without str(), or using bool(input(...)) (see section 04 for why that’s always True).

  


  
4.1.5 Fun Facts

  
Hint 1: the variable names
    
This time the instructions do give you the three names. Copy them exactly, underscores included. Python names are case-sensitive, so has_Pet is a different variable from the one asked for.

  

  
Hint 2: hard-coded values
    
“Hard-coded” means you type the value straight into the program instead of asking the user. Each variable gets one of the two Boolean values, with a capital letter and no quotes. Make them true for you!

  

  
Hint 3: one line per fact
    
Each fact gets its own print, with a short label in front of the value. Look at the sample output in the instructions for the label style, then use either way of printing from section 02.
