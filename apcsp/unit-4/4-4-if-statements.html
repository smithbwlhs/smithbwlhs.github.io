01Anatomy of an if

  
Example 4.4.3 Negative Numbers is the smallest useful if statement:


number = int(input("Number: "))
if number < 0 :
    print("Number is negative.")

  

    
PartIn this exampleJob

    
The keywordifLowercase, always.

    
The conditionnumber < 0Any expression that gives True or False: a Boolean variable, a comparison, or a mix with and/or/not.

    
The colon:Marks the end of the condition. (The space before it in this example is allowed but not needed.)

    
The bodythe indented printRuns only when the condition is True. Indentation is how Python knows which lines belong to the if.

  

  
The example’s comments suggest a second version that stores the comparison in a Boolean instead, like you did in 4.3. Run both with the same number and compare. The highlighted lines are the ones that ran.

  

    
Lab: if vs. storing a Boolean (4.4.3)

    

  

  
Both versions compute the same Boolean. The difference is what happens next: the stored version always prints, while the if version decides whether to print at all. When the number isn’t negative, it prints nothing.

03else: the other path

  
An else block runs when the if condition is False. With if/else, exactly one of the two blocks runs, every time. else never has a condition of its own; it just ends with a colon.

  
Example 4.4.5 Even and Odd uses the modulus operator % from Unit 3. num % 2 is the remainder after dividing by 2: 0 for even numbers, 1 for odd ones.

04Comparing strings

  
Example 4.4.4 Great Names compares text instead of numbers. Read it closely before you run it:


# This program reads the user's name
# and checks if it is equal to "Jeremy"
name = input("Enter name: ")
if name <= "Jeremy":
    print("Great name.")

  
The comment says “equal to,” but the code uses <=. For strings, < and > compare letter by letter, roughly like alphabetical order, so <= means “comes before or is the same as.” Predict what happens for each name below, then run it.

  

    
Lab: run 4.4.4 Great Names

    

  

  
Capitals matter. Python orders characters by their code numbers, and every capital letter comes before every lowercase letter. That’s why "jeremy" <= "Jeremy" is False, and "Zoe" < "adam" is True. To check for exactly one name, use ==.







  
05One decision or two?

  
Two separate if statements are two separate decisions. Python checks both, so both bodies can run, or neither. An if/else is one decision with two outcomes, so exactly one body runs.

  
Here’s a game that hands out badges. Try a score under 100, between 100 and 499, and 500 or more.

  

    
Lab: same input, two programs

    

  

  
Neither program is wrong; they answer different questions. Before you write, ask: “Should only one of these messages ever print, or can more than one print?” Exactly one: use if/else. Each can happen on its own: use separate if statements.







  
06On the AP exam

  
The AP reference sheet calls this selection. The pseudocode uses curly braces { } to mark the blocks, and puts the condition in parentheses.

  


# Python
if score >= 90:
    print("A")
else:
    print("Not an A")


// AP pseudocode
IF (score ≥ 90)
{
   DISPLAY("A")
}
ELSE
{
   DISPLAY("Not an A")
}

  

  
Braces, not indentation, decide what’s inside on the exam. In Python, indentation is the rule. In AP pseudocode, everything between { and its matching } belongs to the block. Exam questions often put an IF inside another block, so match braces carefully and trace from the outside in.
