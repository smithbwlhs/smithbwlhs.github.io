01Constants and sums

Example 4.9.3 For Loop Sum adds up a range of numbers. It starts with two constants:

MIN = 1
MAX = 100

sum = 0
for i in range(MIN, MAX):
    sum = sum + i

print("The sum was " + str(sum))

Writing range(MIN, MAX) instead of range(1, 100) avoids magic numbers: numbers in the code with no explanation. A constant gives the value a readable name, and if you need to change it, you change it in one place.

03Only some numbers

  
What if you only want to add some of the numbers, like the multiples of 5? There are two good ways:

  


# Way 1: check each number with if
total = 0
for i in range(1, n + 1):
    if i % 5 == 0:
        total += i


# Way 2: only visit the numbers you want
total = 0
for i in range(5, n + 1, 5):
    total += i

  

  
Way 1 visits every number and uses % (from 4.4 Even and Odd) to decide whether to add it. Way 2 uses a step (from 4.8) so it never visits the others. Both give the same total.

04Loops inside loops

  
A nested loop is a loop inside the body of another loop. The inner loop runs all the way through on every single pass of the outer loop, like the minute hand going all the way around for every hour. So the total number of passes is outer × inner.


for row in range(1, 4):
    for col in range(1, 5):
        print(row * col)

  
Each loop needs its own variable name. Step through and watch the order: col changes fastest, and row only moves on when col has finished.

05Printing two values

  
When the expected output is exact, like 1,1 in All Dice Values, how you print matters as much as what you print. Here are the ways to print a = 3 and b = 4 on one line:

  

    
CodeOutputWhy

    
print(a, b)3 4A comma between values adds one space.

    
print(a, ",", b)3 , 4Each comma in print adds a space, even around a "," string.

    
print(str(a) + "," + str(b))3,4+ joins strings with nothing in between.

06On the AP exam

  
Accumulator loops and nested loops both show up on the exam in pseudocode. The skill is tracing: keep a table of every variable and update it one pass at a time.

  


// a sum
sum ← 0
n ← 1
REPEAT 4 TIMES
{
   sum ← sum + n
   n ← n + 1
}
DISPLAY(sum)    // 10


// a nested loop
count ← 0
REPEAT 3 TIMES
{
   REPEAT 4 TIMES
   {
      count ← count + 1
   }
}
DISPLAY(count)  // 12

  

  
Nested loops multiply. 3 outer passes × 4 inner passes = 12 times through the innermost line. When an exam question asks how many times a line runs, multiply the counts of every loop around it.

4.9.4 Better Sum

  
Hint 1: two inputs
    
Ask for both numbers and convert each with int() before using them in range.

  

  
Hint 2: include the second number
    
The example 6 to 8 means 6 + 7 + 8, so the second number must be included. stop never is (section 01’s warning). What do you add to the stop to fix that?

  

  
Hint 3: where things go
    
The running total starts before the loop, grows inside it, and gets printed after it (not indented), so you print once instead of on every pass.

  

  
Hint 4: testing
    
6 and 8 should give 21. Also try the same number twice, like 5 and 5: the answer should be 5.

4.9.7 Even Better Sum

  
Hint 1: two ways
    
Section 03 shows two ways to add only some numbers: an if with % (the CodeHS hint), or a range with a step. Either works for even numbers.

  

  
Hint 2: odd n
    
If n is 9, the last even number is 8. Make sure your loop doesn’t skip 8, and doesn’t add 9 or 10.

  

  
Hint 3: testing
    
10 should give 30, 9 should give 20, and 2 should give 2. Print the sum with a sentence like the examples.
