01Three forms of range

FormExampleNumbersMeans
range(stop)range(5)0 1 2 3 4Start at 0, count up by 1, stop before 5. (This is 4.7.)
range(start, stop)range(2, 6)2 3 4 5Start at 2, count up by 1, stop before 6.
range(start, stop, step)range(1, 10, 3)1 4 7Start at 1, add 3 each time, stop before reaching 10.

One rule never changes: stop is never included. The first number is always start. The loop keeps adding step and quits as soon as the next number would reach or pass stop.

02Counting down

A negative step counts backwards. Now start is the big number and stop is the small one, and the loop quits as soon as the next number would reach or go below stop.

Example 4.8.3 Countdown has a comment that makes a promise. Read the comment, then predict the last number before you run it.

The comment and the code disagree. The comment says “ten down to zero,” but range(10, 0, -1) stops before 0, so the last number printed is 1. Comments don’t run; only code does. To include 0, the stop has to be one step past it: -1.

04Growing values

  
Some sequences don’t go up by the same amount each time. Powers of 3 (1, 3, 9, 27, …) multiply by 3 each time, and range can only add a step. There are two ways to handle that:

  


# Way 1: use i as the exponent
for i in range(7):
    print(3 ** i)


# Way 2: a value that keeps growing
power = 1
for i in range(7):
    print(power)
    power = power * 3

  

  
Both print the 7 powers of 3 that are less than 1,000. In Way 2, range(7) only decides how many times the loop runs; the numbers come from power. That’s the running-total pattern from 4.7, using multiplication instead of addition.

  

    
Lab: trace both ways side by side

    
    

    

  

  
Shortcut operators. power *= 3 means exactly power = power * 3. The same works for the others: total += 5, health -= 1. You’ll see them in other people’s code, so it helps to recognize them.

06On the AP exam

  
AP pseudocode has no range. To count by a step, an exam question makes its own counter variable and changes it inside a REPEAT loop.

  


# Python
for i in range(10, 0, -2):
    print(i)


// AP pseudocode
i ← 10
REPEAT 5 TIMES
{
   DISPLAY(i)
   i ← i - 2
}

  

  
Count the passes. Both print 10, 8, 6, 4, 2. The pseudocode needs you to know it’s 5 passes, and many exam questions are exactly that: “how many times does this loop run?” or “what is the value of i after the loop?” (Here it’s 0: the last pass prints 2, then subtracts 2.)
