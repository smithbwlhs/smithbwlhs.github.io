01import and randint

Example 4.12.3 Rolling a Die:

import random

roll = random.randint(1, 6)
print("You rolled a " + str(roll))
PartJob
import randomLoads Python’s random module. It comes with Python but isn’t loaded until you ask, so this line goes at the top of the program.
random.randint(1, 6)Returns a random whole number from 1 to 6, including both ends. The random. in front says which module the function comes from.
roll = …Stores the result so you can print it, compare it, or use it again. Every call picks a new number, so save it if you need the same one twice.

randint is not range. range(1, 6) stops before 6, but random.randint(1, 6) can return 6. For a 1-to-10 number, it’s random.randint(1, 10), not 11.

02Flipping a coin

  
Example 4.12.4 Flipping a Coin makes a random Boolean:


import random

is_heads = random.choice([True, False])
print("You flipped heads: " + str(is_heads))

  
random.choice picks one item from the square brackets. Those brackets make a list, which you’ll learn in Unit 7. You can get the same random Boolean with only what you know now, by combining randint with a comparison from 4.3:


is_heads = random.randint(0, 1) == 1    # True half the time

04Pick once, then decide

  
To choose between several outcomes, pick one random number, store it, and then use an if/elif/else chain from 4.5 to decide what it means. Here’s a weather forecaster with four outcomes.

  


# Right: pick once, store it
pick = random.randint(1, 4)
if pick == 1:
    print("Sunny")
elif pick == 2:
    print("Cloudy")
elif pick == 3:
    print("Rainy")
else:
    print("Snowy")


# Buggy: a new number in every check

05A secret that stays put

  
In a guessing game, the secret number is chosen once, before the loop. The loop keeps asking (a loop and a half from 4.11) until the guess matches. If you pick the secret inside the loop, it changes after every guess and the hints become meaningless.

Smart guessing. Always guess the middle of what’s left: 10, then 5 or 15, and so on. You’ll never need more than 5 guesses for 1 to 20. That strategy is called binary search, and it comes back later in AP CSP.







  
06On the AP exam

  

    
PythonAP pseudocode

    
import random
random.randint(a, b)		RANDOM(a, b) (no import needed)

  

  
The reference sheet says RANDOM(a, b) returns a random integer from a to b, including both, and each result is equally likely, just like randint.

  
Two kinds of exam questions. First: which values are possible? Trace every path the random value could take. Second: simulations. Programs use random numbers to model real events like dice, weather, or traffic, which lets you explore situations that would be slow, expensive, or impossible to test in real life. The trade-off: a simulation is a simplified model, so its results are only as good as its assumptions.
