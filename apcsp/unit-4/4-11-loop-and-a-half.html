Loop and a Half

Sometimes you need to do something before you can decide whether to stop, like ask the user a question and then check the answer. A loop and a half runs “forever” with while True, and jumps out with break the moment the check says you’re done.

1while True:
2 num = int(input("..."))first half
3 if num == SENTINEL:check
4 break
5 sum += numsecond half
The first half runs every pass. The second half runs only when the check doesn’t break. That’s the “half.”

01Why “and a half”?

In 4.10 you added prices until the user typed 0. That version needed the input line twice: once before the loop and again at the bottom. Example 4.11.3 Adding Up Numbers does the same job with the input written only once:

# 4.10 style: ask twice
num = int(input("Enter a number: "))
while num != SENTINEL:
    sum += num
    num = int(input("Enter a number: "))
# 4.11.3: loop and a half
while True:
    num = int(input("Enter a number: "))
    if num == SENTINEL:
        break
    sum += num

while True on its own would never stop, because the condition is always True. The only way out is break, which ends the loop immediately and jumps to the first line after it. The SENTINEL (-1 in the example) is a special “I’m done” value that can’t be mistaken for real data.

03Ask until it’s right

  
The most common loop and a half is input validation: keep asking until the user gives an answer you can use. The pattern is always the same: ask, check, break if it’s good, otherwise complain and go around again.


print("Rate the movie from 1 to 5 stars.")
while True:
    stars = int(input("Stars: "))
    if stars >= 1 and stars <= 5:
        break
    print("Please pick a number from 1 to 5.")
print("Thanks for rating!")

06On the AP exam

  
AP pseudocode has no break or continue, and no while True. The same idea is written with REPEAT UNTIL, and the reference sheet’s INPUT() asks the user for a value.

  


# Python: loop and a half
while True:
    stars = int(input("Stars: "))
    if stars >= 1 and stars <= 5:
        break
    print("Pick 1 to 5.")


// AP pseudocode
stars ← INPUT()
REPEAT UNTIL (stars ≥ 1 AND stars ≤ 5)
{
   DISPLAY("Pick 1 to 5.")
   stars ← INPUT()
}

  

  
The UNTIL condition is the “good answer” test. In the loop and a half, the if that leads to break describes when you’re done. That same condition becomes the REPEAT UNTIL condition. Notice the pseudocode has to ask twice, like the 4.10 version.
