Unit 4

  • 4.1 Booleans

    True, False, and storing them in variables.

  • 4.2 Logical Operators

    Build new Booleans with not, and, and or.

  • 4.3 Comparison Operators

    Compare values with ==, <, >=, and friends, and test the boundaries.

    Run code only when a condition is True, and use else for the other path.

  • 4.6 Key Events

  • 4.7 For Loops

    Repeat code with for i in range(n), draw with loops, and keep a running total.

  • 4.8 General For Loops

  • 4.9 For Loop Practice

    Sums, products, adding only some numbers, and loops inside loops.

  • 4.10 While Loops

    Loop until a condition turns False, and how to avoid infinite loops.

  • 4.11 Loop and a Half

    while True with break, continue, and asking until the answer is valid.

  • 4.12 Random Numbers

    random.randint, random values in loops, and picking once before deciding.

  • Unit 4 Review

    Key ideas from every lesson and a practice test before the 4.13 quiz.
